### 1. Filter data từ 01/07/2026 — `scripts/sync_to_db.js`

Thêm hằng số `CUT_DATE = '2026-07-01'` để loại bỏ đơn cũ khỏi DB sheet:

```js
const CUT_DATE = '2026-07-01';

// Fresh CSV: loại dòng có created_time < 2026-07-01
const freshDataRows = createdTimeIdx >= 0
    ? allFreshDataRows.filter(r => (r[createdTimeIdx] || '') >= CUT_DATE)
    : allFreshDataRows;

// Existing DB rows: cũng loại để dọn sạch dữ liệu cũ
existingDataRows = createdTimeIdx >= 0
    ? allExisting.filter(r => (r[createdTimeIdx] || '') >= CUT_DATE)
    : allExisting;
```

### 2. Alert khi scraper fail — `scripts/run_scraper.bat`

Thêm kiểm tra exit code và popup Windows:

```bat
python scripts\sheet_scraper.py >> scraper_log.txt 2>&1
if %ERRORLEVEL% NEQ 0 (
    set SCRAPER_FAILED=sheet
)

python scripts\rillnet_scraper.py >> scraper_log.txt 2>&1
if %ERRORLEVEL% NEQ 0 (
    set SCRAPER_FAILED=rillnet  (hoặc sheet+rillnet)
)

if defined SCRAPER_FAILED (
    msg * "SD3 Scraper FAIL [%SCRAPER_FAILED%] luc %time% — scraper_log.txt"
)
```

Các fix khác trong bat:
- `set PYTHONIOENCODING=utf-8` — tránh lỗi cp1252 khi in emoji
- Kill Chrome bot theo profile path (không kill Chrome của user)
